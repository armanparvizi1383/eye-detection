# 👁️ Eye Detection & Drowsiness Monitoring

🚗 یک سامانه هوشمند برای **تشخیص خستگی چشم** در رانندگان و کاربران کامپیوتر، پیاده‌سازی‌شده با استفاده از **Python, CNN, OpenCV و Flask**.  
این سیستم به صورت real-time چشم‌های فرد را از طریق وبکم تحلیل کرده و در صورت بسته بودن چشم‌ها به مدت مشخص، هشدار صوتی می‌دهد.

## 🧠 ویژگی‌ها

- 🔍 تشخیص چشم چپ و راست با Haarcascade
- 🧠 طبقه‌بندی باز/بسته بودن چشم‌ها با مدل CNN
- 🔊 پخش آلارم در حالت خواب‌آلودگی
- 💻 نسخه Flask برای اجرا در مرورگر
- 🧪 قابل ارتقاء برای ردیابی نگاه، تشخیص پلک زدن، و غیره
